# QPrakriti Website — Inauguration Edition

A responsive, static website for QPrakriti's early-stage positioning around PQC migration research and engineering.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. For local hosting, run a static server from this folder, e.g. `python -m http.server 8000`, then visit `http://localhost:8000`.

No build step or JavaScript framework is required.

## Before publishing
- Replace `CONTACT_EMAIL` in `index.html` with the company's official email address.
- Confirm the company location and any external contact/social links before adding them.
- Keep the original logo file at `assets/qprakriti-original-logo.jpg`. It is included unchanged from the image supplied for this project. If you receive a transparent PNG/SVG master logo, you can replace the file and update the `<img src>` path.
- Verify all company details and product status.
- Add a real privacy policy and any required legal pages before collecting personal information.
- Set up a production domain, HTTPS, hosting, and any desired analytics only after reviewing privacy requirements.

## Scope and accuracy
The website presents QPrakriti as an emerging PQC migration research and engineering startup. Research and potential outputs are labelled as exploration, not as production-ready product claims. The lifecycle is presented as an explanatory synthesis, not a mandatory official process. Mosca's equation is described as a planning heuristic, not a Q-Day prediction.

## Design
- Responsive layout for desktop and mobile
- Navy, white, and orange visual system
- CSS/SVG animated network illustration
- Mobile navigation
- Reduced-motion accessibility support
- Intersection-based reveal effects
- Semantic sections and basic keyboard accessibility
